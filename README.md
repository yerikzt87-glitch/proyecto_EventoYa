# proyecto_EventoYa
Proyecto de la asignatura Arquitectura de Sistemas Computacionales.

## Problema
EventoYa busca resolver la dificultad que tienen las personas y organizaciones para **gestionar eventos académicos, culturales y sociales**. El sistema facilita la planificación, registro de participantes y administración de actividades, ofreciendo una solución práctica para equipos y comunidades.
